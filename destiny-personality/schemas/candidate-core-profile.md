# Candidate Core Profile Contract

`candidate-core-profile-v1` is an isolated pre-production IR, distinct from
`core-destiny-profile-v1`. Its capability is currently `primitive_only`.

It records candidate evidence, context, salience, stability, modifiers,
counterevidence, cross-system alignment, and context-aware Primitive states.
Opposing directions in different contexts resolve to
`context_differentiated`, not `mixed`. Unknown birth time removes angular and
house modifiers only; eligible planetary aspects remain stable evidence.

Candidate planning may select only existing Primitive evidence. It cannot
derive Signature, Dynamic, Fate Theme, or Archetype. Candidate approval never
opens a strict production route.
