# Core Primitive Ontology Compatibility Review

## Verdict

`SYSTEMATIC_MISMATCH`

The v2 primitives remain coherent product questions, but repeated independent
research shows that several are modern, psychometric-style abstractions rather
than knowledge objects directly represented by Bazi or Hellenistic astrology.
Traditional sources more often express composite character, action, role,
capacity, consequence, and context-conditioned process. Forcing those records
into a high/low preference axis creates semantic ownership errors.

| Primitive | Modern abstraction | Tradition-native nearby constructs | Semantic distance | Bridge feasibility | Ontology compatibility |
|---|---|---|---:|---|---|
| P001 | Self-Directed Judgement | counsel, judgement, authority, command | high | no admitted direct process | weak |
| P002 | Predictability Orientation | steadiness, changeability, fortune stability | high | temperament/outcome collision | weak |
| P003 | Relational Responsiveness | affection, sociability, concord, attachment roles | medium-high | composite and role-heavy | weak |
| P004 | Action Initiation | action, delay, boldness, restraint | medium | nearby behavioral mechanisms exist, but method remains gated | partial |
| P005 | Affect Regulation Orientation | anger, restraint, softness, expression | high | affect state is not regulation preference | weak |
| P006 | Organizational Orientation | handling affairs, administration, skill, disorder | high | capability/outcome collision confirmed by pilot | incompatible |

## Decision boundary

The result does not invalidate the product questions and does not modify or
delete v2. It says only that v2 is a poor first target for source-backed formal
activation. The next experiment must use an **evidence-discovered ontology**:
start with repeated, source-explicit behavioral processes, then test whether a
stable and useful personality abstraction can be owned without importing an
outcome, role, or modern diagnosis.

## Candidate gate

A new primitive must have a direct or behavioral traditional construct, clear
observable process meaning, meaningful variation, context support, and profile
value. It must not be merely outcome, role, capacity, moral praise, or symbolic
analogy. Bazi and astrology need not both contribute evidence, and lack of one
direction never proves the other.

## Versioning decision

Open v3 as an isolated discovery candidate. It has no runtime eligibility, no
migration authority, and no effect on v2 reproducibility. Adoption would require
a separate source, method, counterevidence, evaluation, holdout, Product Owner,
and migration gate.
