# C2-SM P004 Bazi Advancement Semantic Matrix

Date: 2026-10-03

P004 advancement means actively carrying an already undertaken concrete action forward. Diligence, persistence, completion and outcome may qualify that process, but none owns P004 alone.

| Phrase | Start semantics | Continuation semantics | Persistence? | Outcome? | P004 ownership | Result |
|---|---|---|---|---|---|---|

## Ownership decision

One construct passes: the combined `作事進退悔懶、有始無終` claim under a qualified 食遇梟/倒食 method. It is counterevidence that can limit supported-high advancement. It does not establish observation, preparation, restraint or waiting, so `limits_high != supports_low`.

No initiation-support construct and no pre-action Low construct is reopened. No Primitive state, mixed state or global promotion is assigned.
