# v0.8.2 报告质量对比

| 案例 | v0.8.1 | v0.8.2 | 实质变化 |
| --- | --- | --- | --- |
| A | 1 章，0 Signature，0 Dynamic | 3 章，2 Signature，1 Dynamic | 财星—官杀关系由显式规则支持；不是扩写模板 |
| B | 3 章，1 Signature，1 同候选 Dynamic | 5 章，3 Signature，2 Dynamic | 印星—食伤、财星—官杀分别成为可审计关系 |
| C | 3 章，1 Signature，1 同候选 Dynamic | 5 章，3 Signature，2 Dynamic | 与 B 同属两类关系，但证据指纹、事实路径和正文命中值不同 |
| D | 1 章，深层为空 | 1 章，深层为空 | 降级保持，不以新增规则填补缺失时间场景 |

v0.8.2 的提升来自可重放的信号关系和额外的时间敏感宫位上下文。它并未宣称所有命盘都会得到完整长报告，也未把 Theme/Archetype 当成产品配额。十例的章节、Signature、Dynamic 结构见 `docs/validation/v0.8.2/`。

产品质量门结论：A-C 的主轴、关系和限制比 v0.8.1 更可读且可追溯；但 B/C 仍共享两种关系类型，进一步个体化需要更多经过审计的关系资产，而不是改写措辞。
