# Production Semantic Approval Boundary

Candidate semantic approval is not production semantic approval. The
implementation agent may validate candidate assets, publish candidate
pre-releases, and record evidence, but cannot authorize promotion to a
production calculation or reader-facing route.

Production promotion requires a project-owner approval record that names the
exact semantic bundle fingerprint, scope, reviewer, decision date, and the
production capabilities being opened. Until that record exists, strict
production gates remain closed.
