# v0.8.1 报告基线逐章复核

## 冻结范围

本复核直接阅读 `docs/validation/v0.8.0/` 的 A、B、C 三份用户报告及其 facts、qualification、CDP、plan、audit。三者均使用合格的本地计算事实；问题发生在审计解释画像的综合和呈现层，而非计算或资格校验。

## 逐章发现

| 案例 | 实际问题 | 代码根因 |
| --- | --- | --- |
| A | “核心画像”混合一个宫位线索和一个方向并列；“张力”重复相同句子；影子、主题、原型均无独立机制。 | `_dynamics` 逐条复制 alignment；`_shadow_mature`、`_themes`、`_archetype` 分别按 signature 排名生成。 |
| B | 多出日月相位线索，但它没有与另一倾向建立可审计互动；原型仍由主题名称拼接。 | planner 把可用条目当作深层结构，不要求 interaction evidence。 |
| C | 与 B 的章节骨架近似；标题变化主要来自方向词，叙事没有解释倾向如何相互作用。 | planner 固定选择顺序，renderer 直接连接 `statement`。 |

所有三例都有明显换词重复：核心画像中的 alignment 在下一节再次原样出现；Shadow/Mature 的正文完全相同；Theme 只是 signature 前缀；Archetype 只是两个 topic 的连接。现有输出没有发现超出规则来源的命盘事实，但对“张力”“生命主题”“原型”的结构性表述超出了其可用互动证据。

## 基线冻结

v0.8.0 产物保持在 `docs/validation/v0.8.0/`，不修改。v0.8.1 以相同 A/B/C 输入生成新 artifacts，并在比较报告中逐项说明差异。低覆盖 D 使用既有合格的 `missing-time` fixture，验证可为空的深层结论链。
