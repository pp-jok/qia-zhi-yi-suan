# v0.8.2 解释规则覆盖审计

## 结论

本轮确认短报告的首要原因不是 Renderer，而是两处上游缺口：规则信号未被作为单体系显著结构评估，且 Dynamic 没有版本化的互动关系资产。v0.8.2 在不改变事实资格、Primitive、Mapping 或 `PRIMARY_EVIDENCE` 的前提下，补入 2 条时间敏感上下文规则与 3 条解释关系规则。

## 质量审计

每条新增资产均包含传统参考、匹配条件、机制、情境、反向/不适用条件和限制。关系规则只消费已匹配信号 ID；同一事实派生多个措辞不会充当独立支持。没有规则被提升为正式语义核心资产。

## 未覆盖项与优先级

1. 高：Provider 仅支持上海/北京，且部分日期存在角点—角点相位校验错误；这是输入链路限制，不通过规则层掩盖。
2. 中：金星、木星、土星宫位，以及非日月主要相位仍没有审计型解释规则。
3. 中：八字月令、五行环境、显隐来源只作为事实/限定背景，未被不当地转化为强弱或用神结论。
4. 低：Theme/Archetype 缺少两条共享结构与情境的关系实例；当前保持为空是正确的降级结果。
