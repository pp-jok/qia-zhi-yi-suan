# v0.8.1 深层语义质量对照

## 实际变化

| 项目 | v0.8.0 | v0.8.1 |
| --- | --- | --- |
| Alignment | 自动转 Dynamic | 保留为比较证据，不自动升级 |
| Dynamic | 同主题方向并列 | 仅多方向、多机制候选形成 `contextual_sequence` |
| Shadow/Mature | 前三个 Signature 的相同话术 | 仅从 Dynamic 导出，明确为待验证假设 |
| Theme | Signature 改名 | 至少两条 Dynamic 的共同情境；本轮样本均为空 |
| Archetype | topic 名称拼接 | 要求 Theme + 两条 Dynamic；本轮样本均为空 |
| Planner | 固定 4–8 节骨架 | 1–7 节，按真实可用层级选择 |
| Renderer | 拼接 statement | 按主张、机制、情境、压力/整合按需组织；Shadow 不重复 Dynamic 机制 |

## 四案例逐章复核

- A：v0.8.0 为 6 节并包含无机制的张力、通用 Shadow、Theme 和 Archetype；v0.8.1 为 1 节“当前可支持观察”。没有形成 Dynamic、Theme 或 Archetype。问题不是被隐藏，而是明确降级。
- B：v0.8.0 为 5 节，深层条目多为模板。v0.8.1 为 3 节：核心主轴、由“反思—外化”双方向及两个机制支持的内在节奏、从该节奏受控导出的压力与成熟调节。Theme/Archetype 为空。
- C：v0.8.0 为 6 节。v0.8.1 同样是 3 节，拥有与 B 同类的八字表达节奏，但第二条占星行动观察的实际模式为“土象/开创”而非 B 的“土象/固定”；报告保留该差异，同时不声称它已构成第二个 Dynamic。
- D：使用现有的合格 `missing-time` 低覆盖 fixture。输出 1 节支持观察，深层结果全空；没有因章节不足而失败。

## 仍未解决的限制

本轮未增加新的解释规则或批准 mapping。因此，A 与 D 的完整人格叙事会显著变短；B/C 也不能形成 Fate Theme 或 Archetype。它是现有规则资产的真实覆盖边界。要获得更多可审计的跨体系动态，需要新增并审查明确的互动机制规则，而不是在 renderer 中添加文字。

## 验收结果

- Alignment 不自动升级为 Dynamic：通过。
- Shadow/Mature 有 Dynamic lineage 且非固定建议：通过。
- Theme 与 Archetype 在证据不足时为空：通过。
- Planner 无最小四章要求：通过。
- 四案例 artifacts 已保存至 `docs/validation/v0.8.1/`：通过。
- B/C 的深层结构仍有同源规则造成的相似性：已披露，未伪装为个体化差异。
