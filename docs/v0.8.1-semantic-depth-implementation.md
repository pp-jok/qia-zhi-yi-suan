# v0.8.1 深层语义综合实施说明

`AuditedProfileItem` 增加来源、关系、激活情境、机制、压力/整合模式、反证与派生等级字段。所有字段从已匹配的解释规则候选或受控组合获得，并继续保留 signal/rule/fact provenance。

Dynamic 的允许关系为 `contextual_sequence`、`reinforcement`、`contextual_switch`；没有满足精确条件时不产生 Dynamic。Shadow/Mature 使用相同 dynamic 的 pole、机制和情境，且明确是需要读者验证的反思性假设。Theme 与 Archetype 均可为空。

planner 不设置最小章节数。它先给出核心主轴或当前可支持观察，再按实际存在的 Dynamic、Shadow/Mature、Theme、Archetype 安排解释；相同 item 不在多章重复。renderer 生成“主张—依据—机制—情境—整合/限制”的按需叙事段，并不读取原始事实、规则目录或 candidate assets。
