# v0.7.0 实施计划

1. 新增本地 provider 与出生信息解析：固定地点目录（首版覆盖上海及可显式经纬度输入）、IANA 时区、标准时间与真太阳时记录。
2. 用 MIT 历法/天文依赖计算四柱、藏干、十神、五行相克关系；计算十星体、整宫房位、角点、主要相位和四类尊贵度。
3. 把计算结果编码为既有 `deterministic-facts-v1`，再由独立的本地验证器产生 `fact-qualification-v1`；资格记录必须包含 provider 版本、方法版本、校验和与计算信封引用。
4. 新增 `build-birth-report` CLI：它是唯一正常用户入口，自动写出 report、facts、qualification 与 execution audit；原 facts CLI 保持为高级审计入口。
5. 用真实输入做端到端测试，覆盖依赖缺失、无效出生信息、未知地点、计算失败、事实篡改和干净安装。

`gender` 被保留在审计输入中；当前人格解释规则不按性别分支，报告不会借此制造未经定义的差异。
