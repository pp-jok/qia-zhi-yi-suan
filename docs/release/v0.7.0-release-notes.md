# v0.7.0 — Birth-input product chain

- Adds a local, deterministic birth-input CLI that calculates, qualifies, and renders an audited interpretive report.
- Uses MIT-licensed `lunar_python` and `astronomy-engine`; no remote transfer or model-generated chart facts.
- Declares the Western output as tropical whole-sign, rather than mislabelling it as Placidus.
- Emits facts, qualification, and execution artifacts beside each report.
- Makes `standard-interpretive-v1` the default report produced by the birth-input CLI.

Known v0.7 boundary: the bundled city registry currently supports Shanghai and Beijing. Unsupported locations fail explicitly; they are not geocoded remotely or guessed.
