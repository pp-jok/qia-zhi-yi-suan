# 掐指一算 v0.8.2 · 解释关系与覆盖整改

v0.8.2 为 `core-profile-v1` 增加可审计的 relationship（关系）规则。Dynamic 仅在明确的、方向限定的前提信号全部命中时生成；它不再由 Alignment、关键词、共同情境或信号数量自动推出。

本版新增印星—食伤、财星—官杀和日月功能三条关系规则；扩展水星与火星宫位上下文。所有新增内容都保留传统参考、事实路径、限制和反向条件，且不会创建 Primitive、Mapping 或 `PRIMARY_EVIDENCE`。

十组验证产物与规则覆盖、证据漏斗、质量比较位于 `docs/validation/v0.8.2/` 及同级 v0.8.2 审计文档。低证据案例继续保持单章降级。

本版继续使用本地（local）Provider 的 tropical whole-sign 计算与 qualification 边界；`standard-interpretive-v1` 兼容路径保持可用。新增关系不改变事实计算、资格校验或严格路径。
