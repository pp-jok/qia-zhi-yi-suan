# v0.6.0 Internal Test Product Release Notes

v0.6.0 turns the audited interpretive path into an internal test product that
starts with ordinary birth information. The Skill discovers and invokes an
available calculation/qualification provider; if none is available, it
returns `CAPABILITY_GAP` and stops. It never asks a normal user for facts JSON
or substitutes free-form chart calculation.

## Product changes

- Replaced demo-shaped interpretation entries with reusable Bazi and astrology
  rule families, including a bounded four-element/three-modality narrative
  table that changes reader semantics beyond the evidence label.
- Added system-specific profiles, explicit alignment/tension synthesis, deeper
  reader-first composition, and provenance for every supported conclusion.
- Added 12 qualification-bound product fixtures and five reproducible v0.6.0
  demos. Normal complete fixtures expose at least six real topics; sparse
  evidence stays short.
- Standard reports keep the 12-section ceiling by consolidating overflow
  conclusions with complete provenance. The agreement fixture now proves an
  exact-topic, same-direction cross-system validation rather than visual
  co-location.
- Preserved `stable_only` behavior: missing birth time visibly omits the hour
  pillar, houses, Ascendant, MC, angles, and dependent claims.
- Kept `standard-interpretive-v1` as the default report and
  `concise-interpretive-v1` as its shorter view.

## Compatibility

All v0.5.0 routes remain intact. Explicit audit, research, and
project-rule-deterministic requests still use `strict`; formal
limited-coverage, Candidate Preview, and explicit 56-chapter legacy routes
retain their existing gates and isolation.

## Package and verification

The Python package and wheel are version 0.6.0. The wheel includes the
versioned interpretive rule asset and existing canonical, candidate, and
release YAML assets. Release verification requires the complete pytest suite,
wheel build and asset inspection, plus the configured Python 3.9/3.11/3.12 CI
matrix. Public publication remains conditional on green merged-branch CI.

This release remains a traditional interpretive aid, not an empirical
personality, psychological, medical, legal, or financial assessment.
