# qia-zhi-yi-suan v0.8.1

v0.8.1 hardens the audited core-profile synthesis boundary. Cross-system alignment is no longer treated as a personality dynamic by itself. A dynamic now requires a candidate with multiple matched directions and mechanisms; shadow/mature is derived only from that dynamic; themes and archetypes are omitted unless their independent lineage thresholds are met.

The default report planner permits an evidence-limited short report. The renderer adds mechanism, activation context, pressure and integration only when those fields exist, while preserving signal, rule and fact provenance. No candidate mapping is promoted and the formal primitive release path remains unchanged.

The local provider, qualification boundary, tropical whole-sign calculation method, and explicit `standard-interpretive-v1` compatibility mode remain unchanged.
