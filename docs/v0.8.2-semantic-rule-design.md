# v0.8.2 规则与关系设计

解释规则继续负责“事实 → 有限定的传统信号”；新关系资产负责“已匹配信号 → 有条件的互动结构”。两层均从 Qualified Facts 出发，且都不读取正式 Mapping 或 Primitive 资产。

Dynamic 的最小证据为：版本化关系规则、全部方向限定的来源信号、来源规则引用、具体事实路径、机制、情境、压力假设、整合假设和不适用条件。`_dynamics()` 不再查看候选的方向数量或机制数量。

Signature 的单体系入口要求同一候选拥有至少两个已匹配信号与至少两条具体事实路径；这是一种显著度门，不是独立证据的科学声明。Theme 还要求两个关系 Dynamic 共享关系类型与情境；Archetype 仅在 Theme 存在时摘要生成，且不用固定名称。

报告 Renderer 只显示上述已有结构，并新增“**不适用或需要收紧的条件**”。它不计算关系、不生成新事实，也不填补 Theme 或 Archetype。
