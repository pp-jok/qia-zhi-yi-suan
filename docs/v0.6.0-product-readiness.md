# v0.6.0 Product Readiness

Status: **release ready as an internal test product**

The normal workflow accepts birth information, uses an available
calculation/qualification provider, and stops with `CAPABILITY_GAP` when that
capability is unavailable. Facts JSON is an internal interface, not a user
prerequisite. The workflow never substitutes free-form model calculation.

## Product gates

- Require qualified facts before interpretation and preserve fact, rule,
  signal, qualification, and fingerprint provenance.
- Keep normal complete fixtures at six or more real reader topics; permit
  sparse evidence to yield a shorter report.
- Omit time-sensitive scope and show the limitation when birth time is absent.
- Preserve every v0.5.0 strict route and its fail-closed gates.
- Run the full test suite and wheel build; inspect the wheel for packaged
  `interpretive_assets/v1/interpretive_rules_v1.yaml`.
- Keep the Python 3.9, 3.11, and 3.12 CI matrix plus package verification
  configured. Publication remains conditional on the merged branch CI run.

## Release boundary

This status approves an internal test product, not a scientific personality
instrument or an unconditional public publication. No calculator, native
ephemeris, user birth data, or unqualified facts are bundled.
