# Autonomous Decision Records

Decision documents referenced by
`governance/autonomous-completion-v1/decision_registry_v1.yaml` provide the
human-readable audit trail for delegated autonomous work.

Every registry entry must bind one asset and its exact fingerprint, cite
evidence and tests, and use `delegated_autonomous_executor` with
`AUTONOMOUS_COMPLETION` mode. This directory does not contain or simulate human
Product Owner decisions.
